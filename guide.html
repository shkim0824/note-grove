NOTE GROVE · 나의 연구 노트

Note Grove, 이렇게 쓰세요.

GitHub 저장소에 보관되는 노션 같은 노트예요. 비공개 노트와 공개 노트를 한 화면에서 쓰고, 페이지마다 공개 여부를 바꿀 수 있어요.

내 노트 열기 →

1. 처음 연결하기

  1. GitHub에서 fine-grained 토큰 만들기 ↗를 엽니다.
  2. Repository access → Only select repositories → ai-notes와 ai-notes-public 두 개를 고릅니다.
  3. Permissions → Contents: Read and write를 고르고 토큰을 만듭니다. 다른 권한은 필요 없어요.
  4. 앱 왼쪽 아래 🔑 GitHub 연결 → 토큰을 붙여 넣고 연결을 누릅니다.
  5. 이 브라우저에 토큰 기억하기를 켜 두면 다음부터 자동으로 연결돼요. 노트북마다 한 번씩 입력하면 됩니다.
토큰은 이 브라우저에만 보관되고 GitHub API로만 전송돼요. 앱 저장소나 노트 저장소에는 올라가지 않아요. 토큰 없이 열면 공개 페이지만 읽기 전용으로 보여요.

2. 페이지 쓰기

노션처럼 블록 단위로 씁니다. 빈 줄에서 /를 누르면 블록 메뉴가 열려요.

3. 저장

  • 입력을 멈추고 약 1.5초 뒤 GitHub에 자동 저장돼요(오래 이어서 쓰면 15초마다). ⌘S로 바로 저장할 수 있어요. 오른쪽 위에 편집 중… → 저장 중… → 저장됨이 표시돼요.
  • 저장 하나가 커밋 하나예요. 고친 블록만 바뀌고 나머지 원문은 그대로 남아서 GitHub의 변경 기록이 깔끔해요.
  • 인터넷이 끊기면 내용이 이 브라우저에 초안으로 보관되고, 다시 열 때 초안 복구를 물어봐요.
  • 다른 노트북에서 바꾼 내용은 창으로 돌아올 때와 30초마다 확인해서 반영해요. 두 곳에서 같은 페이지를 동시에 고치면 충돌 창이 떠요 — 내 버전으로 덮어쓰거나, 다른 곳의 버전을 불러오고 내 버전은 .md로 내려받을 수 있어요.

4. 🔒 비공개 · 🌐 공개

  • 비공개 페이지는 shkim0824/ai-notes(private), 공개 페이지는 shkim0824/ai-notes-public(public)에 저장돼요.
  • 페이지 위의 🔒 비공개 단추 → 공개로 옮기기. 링크한 이미지·PDF도 공개 저장소로 복사되고, 하위 페이지를 함께 옮길지 고를 수 있어요.
  • 공개 페이지는 토큰 없이 누구나 이 사이트(…/note-grove/#/p/페이지ID)와 GitHub에서 읽을 수 있어요. 공유 단추로 링크를 복사하세요.
  • 공개한 페이지도 왼쪽 목록에서는 원래 자리에 🌐 표시와 함께 남아 있어요.
주의 — 공개 저장소에 한 번 올라간 내용은 나중에 비공개로 돌려도 커밋 기록, 다른 사람의 포크, 검색 캐시에 남을 수 있어요. 공개하기 전에 내용을 확인하세요. 공개 페이지는 저장할 때마다 바로 공개돼요.

5. 기록 (GitHub 커밋)

페이지 위의 🕘 기록에서 저장된 모든 버전을 볼 수 있어요. 버전을 고르면 그때의 내용을 미리 보고, 이 버전으로 되돌리기를 누르면 그 내용이 새 버전으로 저장돼요(이후 기록도 지워지지 않아요).

6. 정리하기

  • 휴지통: 페이지 메뉴(⋯) → 휴지통으로. 왼쪽 아래 🗑 휴지통에서 복원하거나 영구 삭제해요. 영구 삭제해도 GitHub 기록에는 남아 있어요.
  • 템플릿: 페이지 메뉴 → 템플릿으로 지정. ＋ 새 페이지에서 템플릿으로 시작할 수 있어요.
  • 레포 파일 가져오기: git이나 GitHub에서 직접 추가한 .md 파일을 페이지 목록에 등록해요.
  • 옮기기: 왼쪽 목록에서 페이지를 끌어 순서를 바꾸거나 다른 페이지 안에 넣어요.
  • 내보내기: ⋯ → Markdown 내려받기, 인쇄 · PDF로 저장.

8. 보안

  • 토큰은 두 노트 저장소의 Contents 권한만 주세요. 토큰이 새었다고 생각되면 GitHub 설정에서 바로 삭제하고 새로 만드세요.
  • “토큰 기억하기”는 개인 기기에서만 켜세요. 같은 주소(shkim0824.github.io)의 다른 앱과 브라우저 저장 공간을 함께 써요.
  • 앱은 GitHub API와 GitHub 원문 주소에만 접속하도록 막혀 있어요(다이어그램 라이브러리만 jsDelivr에서 받아요).
